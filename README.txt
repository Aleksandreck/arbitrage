# Crypto Arbitrage Scanner

Pet-проект на Python: сканер арбитражных возможностей между криптовалютными биржами через публичные API (без API-ключей).

## Что делает
- Подключается к нескольким биржам через `ccxt` (по умолчанию Binance и Bybit).
- Загружает тикеры спотовых пар к выбранной котируемой валюте (например, `USDT`).
- Сравнивает `ask` на одной бирже и `bid` на другой.
- Считает валовый и чистый спред с учётом комиссий.
- Выводит таблицу лучших возможностей и сохраняет результат в CSV.

## Важно
Проект **не является инвестиционной рекомендацией** и не выполняет реальные сделки. Это учебный/исследовательский инструмент для анализа рыночных данных. Не учитываются лимиты на вывод, глубина ордербука, скорость перевода и проскальзывание.
